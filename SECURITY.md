# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.1.x | Yes |
| 1.0.x | Security fixes only |

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities (such as session encryption flaws, webhook token bypasses, or MTProto key handling issues).

Instead, report the issue privately via GitHub Security Advisories on the repository with:
- Affected module and version
- Minimal reproduction steps
- Impact assessment

You will receive an initial response within 72 hours.
